# tumbler_api_tg_bot

Телеграм-бот для скачивания медиафайлов из Tumblr по ссылке. Написан на Python (aiogram 3).

## Возможности
- Скачивание картинок, видео и гифок.
- Защита от спама (пока обрабатывается одна ссылка, новые не принимаются).

## Как запустить локально
1. Клонируйте репозиторий: `git clone ...`
2. Установите зависимости: `pip install -r requirements.txt`
3. Создайте файл `.env` на основе `.env.example` и вставьте свои токены.
4. Запустите: `python main.py`

## Стек
- Python 3.x
- aiogram 3
- requests / aiohttp
